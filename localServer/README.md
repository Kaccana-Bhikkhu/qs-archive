# Running the Ajahn Pasanno Archive on a local server

LocalServer.py is a simple script that creates a local web server hosting the Ajahn Pasanno Archive and opens the default browser to the home page. It has no security protections and is meant only for personal use and testing purposes.

To use it, install python on your device and run LocalServer.py, either by double clicking this file or through the command line, e.g. `python qs-archive/localServer/LocalServer.py`.

On Android it's probably easier to use Simple HTTP Server. On iOS you could try Simple Server:HTTP Server. I haven't tested these myself.
